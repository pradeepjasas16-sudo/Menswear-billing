HOW TO GET YOUR APK (no Android Studio needed)

1. Create a free account at github.com and sign in.
2. Tap "+" > New repository. Name it menswear-billing. Create it.
3. Upload ALL files from this folder (including the hidden
   .github folder) using "uploading an existing file".
   Easiest on a computer: unzip, then drag everything in.
4. Open the Actions tab. The "Build APK" workflow starts by itself
   (or tap Run workflow). Wait about 5 minutes for the green tick.
5. Open the finished run, scroll to Artifacts, download
   menswear-billing-apk, unzip it to get app-debug.apk.
6. Copy the APK to your Android phone and open it. Allow
   "Install unknown apps" when asked.

To change the shop name, items or prices: edit www/index.html.
